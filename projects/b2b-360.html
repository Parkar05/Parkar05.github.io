The problem

Management needed to see the whole B2B business in one place. Financials, the subscriber base, sales activity, churn, devices, the sales pipeline, waivers and incentives were all reported separately, from five different systems.

What I built

I built one star-schema model over all five sources (hundreds of millions of rows at source). A 360° home page shows the headline KPI from every area, and each KPI opens a detailed page.

Impact: 13 drill-through pages behind a single 360° KPI home page

How it's built

  • Star schema with conformed contract, KAM and date dimensions shared across 13 subject areas
  • Power Query unions of GA, churn and upgrade/downgrade events, with KAM-segment mapping
  • Bridge (waterfall) logic driven by a disconnected axis table and TREATAS
  • Time intelligence: YTD, CY vs PY, budget-to-date, projected year-end
  • Voucher cohort analysis, Deneb custom visual, page-navigation UX with buttons

DAX highlight

Revenue bridge: one measure drives every bar

VAR CategoryName =
    SELECTEDVALUE ( '360 Revenue Bridge Axis'[Bridge Category] )
RETURN
    SWITCH (
        TRUE (),
        CategoryName = "Budget", [360 Gross Revenue Budget Actual Period],
        CategoryName = "Actual", [360 Gross Revenue Actual],
        CALCULATE (
            [360 Gross Revenue Actual] - [360 Gross Revenue Budget Actual Period],
            KEEPFILTERS ( '360_Fact_PNL'[P&L Type] = "revenue" ),
            KEEPFILTERS ( '360_Fact_PNL'[Include in P&L] = "Yes" ),
            TREATAS ( { CategoryName }, '360_Fact_PNL'[360 Revenue Stream] )
        )
    )

Weighted pipeline

COALESCE (
    CALCULATE (
        SUMX (
            SalesForce_Pipeline,
            SalesForce_Pipeline[AMOUNT] * DIVIDE ( SalesForce_Pipeline[PROBABLITY], 100 )
        ),
        KEEPFILTERS ( SalesForce_Pipeline[Pipeline Status] = "Open" )
    ),
    0
)
