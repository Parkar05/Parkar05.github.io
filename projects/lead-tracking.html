The problem

An enterprise deal passes through Pre-Sales, Pricing, Marketing, Finance, CFO, Revenue Assurance, Charging and Collections. KAMs had no single place to see where a lead was stuck, so they visited or called team after team, and often heard “it’s not with us”.

What I built

The report reads the opportunity (OP) and purchase-order (PO) lists. For each lead it shows the latest stage in plain language, the team that owns it now, and the value at stake, so the KAM goes straight to the right team.

Impact: Saves each KAM ~30 minutes a day of calling teams to chase leads

The lead journey it tracks

New request→Pre-Sales review→Pricing / EPM→Marketing→Finance→CFO / CEBO→Revenue Assurance→PO: Charging→Invoicing & collection→Paid

How it's built

  • Latest-status logic per lead using the most recent entry
  • System status codes translated into plain-language ‘who has it now’ labels
  • De-duplicated PO value (SUMX over SUMMARIZE) so multi-line POs aren’t double counted
  • Segment and KAM slicers for managers; KAM view for day-to-day follow-up

DAX highlight

Latest PO stage → who owns it now

VAR LatestDate = MAX ( fact_POEntry[Created] )
VAR CurrentStage =
    CALCULATE ( SELECTEDVALUE ( fact_POEntry[Stage] ), fact_POEntry[Created] = LatestDate )
RETURN
    SWITCH (
        CurrentStage,
        "Sale Approval",       "Under Review - Charging Team",
        "Charging Approval",   "Pending Charging",
        "Collection Approval", "Pending Invoicing / Collection",
        "Request Closed",      "Invoice Paid",
        "Sale Rejected",       "PO Rejected - Charging Team",
        CurrentStage
    )
