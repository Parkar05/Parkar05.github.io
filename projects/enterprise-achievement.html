The problem

Enterprise achievement depends on PO services, their category and the quarter they were signed, plus manual adjustments. Tracking it against category targets was slow and easy to dispute.

What I built

The model combines PO services with an adjustments list and maps every service to a target category. Cumulative target, achievement % and remaining target are calculated per category. A single payout measure works for a KAM, a segment manager or the whole team.

Impact: Cumulative target, remaining gap and payout for every KAM and segment

How it's built

  • Union of PO services and target adjustments into one achievement fact
  • Service-to-target-category mapping table
  • Cumulative (quarter-to-date) targets that ignore the date filter
  • Context-aware payout: KAM, segment manager or total

Payout that adapts to what is selected

VAR HasKAM     = HASONEVALUE ( Employee_Master[KAM_Name] )
VAR HasSegment = HASONEVALUE ( Employee_Master[Segment] )
VAR KAMPayout     = SUMX ( VALUES ( Dim_TargetCategory[Category] ), [Incentive - KAM Payout] )
VAR ManagerPayout = SUMX ( VALUES ( Dim_TargetCategory[Category] ), [Incentive - Manager Payout] )
RETURN
    SWITCH (
        TRUE (),
        HasKAM,     COALESCE ( KAMPayout, 0 ),       -- one KAM selected
        HasSegment, COALESCE ( ManagerPayout, 0 ),   -- one segment selected
        COALESCE ( [Incentive - Total KAM Payout Card], 0 )
            + COALESCE ( [Incentive - Total Manager Payout Card], 0 )
    )
