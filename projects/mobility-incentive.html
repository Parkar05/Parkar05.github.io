The problem

Commission was worked out in spreadsheets at quarter end. KAMs couldn't see how they were tracking during the quarter, and checking the numbers took a lot of manual work.

What I built

Mobility transactions (GA, churn, upgrades, downgrades) are unioned into one fact table, measured against quarterly MRC targets, and mapped to a payout grid by segment. Management sees every KAM; each KAM sees only themselves through RLS.

Impact: One version of the truth for KAM payouts, with a row-level-security view per KAM

Inside the report

What each page answers

Executive viewAchievement % vs target, run rate, final payout by segment and KAM
Achievement driversGross add, upgrade, downgrade and churn MRC impact
KAM detailContract and line-level transactions behind each number

How it's built

  • Power Query union of GA/churn and upgrade/downgrade events with segment mapping
  • Run-rate and achievement measures that follow the selected quarter
  • Payout lookup against a tiered achievement grid per segment (Large / Medium / FONZ)
  • Manager payouts roll up their team; RLS for the KAM version

DAX highlight

Run rate for the selected quarter

VAR Qtr = [Selected Quarter]
VAR CurrentQtr = COALESCE ( Qtr, MAX ( Dim_Date[Quarter Number] ) )
RETURN
    [2 Dashboard_Base_MRC]
        + CALCULATE (
            [1 Total Achievement],
            FILTER ( ALL ( Dim_Date ), Dim_Date[Quarter Number] = CurrentQtr )
        )
